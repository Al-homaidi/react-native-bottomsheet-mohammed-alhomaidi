## [1.0.0] - 2024-01-XX

### Added
- Initial release of React Native BottomSheet
- Context-based API with `useBottomSheet` hook
- Multiple sheets support
- Smooth animations with React Native Reanimated
- TypeScript support with comprehensive type definitions
- Component-based content system
- Highly customizable styling options
- Multiple snap points support
- Built-in backdrop with customizable opacity
- Draggable line for interactive expansion/collapse
- Support for custom styles and CSS classes
- Keyboard handling and dismissal
- Performance optimizations
- Cross-platform compatibility (iOS & Android)

### Features
- `snapTo`: Initial snap position
- `snapToExpanded`: Expanded snap position for drag-to-expand
- `expandToFull`: Programmatic full-screen expansion
- `backgroundColor`: Custom background colors
- `DropbackgroundColor`: Custom backdrop colors
- `containerStyle`: Custom container styling
- `lineContainerStyle`: Custom line container styling
- `lineStyle`: Custom line styling
- `containerClassName`: CSS class names for container
- `lineContainerClassName`: CSS class names for line container
- `lineClassName`: CSS class names for line
- `zIndex`: Custom z-index management

### Examples
- Basic usage example
- Settings bottom sheet
- Action sheet
- Form with auto-expand on focus
- Multiple sheets example
- Custom styled sheets
- Comprehensive example using all properties
